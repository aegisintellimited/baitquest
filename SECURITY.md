# Security Policy

Security, privacy, data integrity and recoverability are release requirements for BaitQuest.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.

Until a dedicated security contact is published, contact the project maintainers privately through the GitHub profile or organisation contact channel. Include, where safe:
- A concise description and potential impact.
- Steps to reproduce.
- Affected version or commit and environment.
- Any suggested mitigation.

Do not include real personal data, credentials, tokens, customer information or other secrets in reports.

## Scope and response

BaitQuest is currently in product discovery and scaffold preparation. A formal supported-version policy, security contact and response timelines will be established before production release. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.
